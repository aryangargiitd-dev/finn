CORE FEATURE 3: FINN REALITY CHECK

This is our main product differentiator.

Goal:
Help investors compare management's stated expectations with actual subsequent performance.

Create a focused research workflow that answers:

"What did management say would happen, and what actually happened?"

A. Management statement extraction

Read earnings-call transcripts and extract explicit forward-looking statements.

Examples:
- Revenue growth expectations
- Margin guidance
- Capital expenditure guidance
- Capacity expansion plans
- Debt reduction targets

Record:
- Exact quoted statement
- Speaker, if available
- Statement date
- Metric
- Expected value or direction
- Target period
- Document citation

Do not transform vague optimism into numerical guidance.

B. Actual performance

Retrieve the relevant subsequently reported results.

Match the realized metric and reporting period to the earlier guidance.

C. Comparison

Display:

Management expectation
→ Actual reported result
→ Variance, where mathematically comparable
→ Evidence-based assessment

Possible statuses:
Met
Missed
Partially met
Not yet due
Not comparable
Insufficient evidence

Do not force classifications where guidance is ambiguous.

D. Presentation

Build a beautiful visual comparison component with:
- Expected metric
- Actual metric
- Comparison status
- Short interpretation
- Links to both original documents

This feature should feel like a useful proprietary research workflow, not a generic AI summary.

Start with ONE deeply supported company example.

Expand only after that example works reliably.
